# SpaceX Plotly Dash (IBM capstone)

**Files:** `SpaceX_Plotly_Dash_Completed.ipynb` (lab walkthrough), `spacex_dash_app.py` (runnable Dash server), `spacex_launch_dash.csv` (56-launch historical dashboard sample).

## Run in normal Python (not JupyterLite)

1. Install Python 3.10+ and open terminal in this folder.
2. Run `python -m pip install -r requirements.txt`.
3. Run `python spacex_dash_app.py`.
4. Open `http://127.0.0.1:8050` in your browser.
5. Capture screenshots of all-sites pie, specific-site pie, and payload slider scatter.

This is the historical **56-launch** dataset, not IBM's **90-launch** modeling dataset. The interactive app is coded and local figure callbacks validated, but a live web-browser session has not been captured here. It is not correct to claim the notebook executed in JupyterLite.
